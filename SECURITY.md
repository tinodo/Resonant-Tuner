# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/tinodo/Resonant-Tuner/security/advisories/new)
rather than opening a public issue. You can expect an acknowledgement within a
few days.

## Scope

Resonant Tuner runs entirely on your device. It has no network features, accounts
or telemetry, and it does not store audio or settings on disk. Reports about
dependencies, the build and release pipeline, or the packaging are all welcome.
