# Resonant.Core

The UI-free engine behind [Resonant Tuner](https://github.com/tinodo/Resonant-Tuner), an offline instrument tuner for Windows: pitch math, a YIN-style pitch estimator, pitch tracking, spectrum analysis, instrument tunings and sessions, reference-tone synthesis and the tuner controller. User-visible strings come in English, Dutch, German, French and Spanish.

Targets .NET 10 and depends only on [MathNet.Numerics](https://numerics.mathdotnet.com/). It has no WinUI or WinRT dependency.

The package is published to GitHub Packages by the release workflow of the repository. See [Using Resonant.Core](https://github.com/tinodo/Resonant-Tuner#using-resonantcore) for the feed and how to authenticate.
